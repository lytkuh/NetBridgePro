# NetBridge Pro — Wire Protocol / پروتکل سیم

Single source of truth for both implementations:
`android/app/.../bridge/BridgeServer.kt` ⇄ `windows/src/Bridge/BridgeClient.cs`
and `android/.../proxy/MultiProxyServer.kt` ⇄ `windows/src/Net/LocalProxy.cs`.

## 1. Ports

| Port | Side | Purpose |
|---|---|---|
| 59110 | phone | multiprotocol proxy (SOCKS5 / SOCKS4a / HTTP) |
| 59120 | PC (loopback) | local proxy for Windows apps |
| 59123 | phone | control bridge (JSON lines) |
| 5038 | PC (loopback) | private adb server |
| 59121 / 59122 | PC loopback | adb forwards → 59110 / 59123 |

## 2. Credentials

- **Token**: 32 hex chars. Generated by the *Windows* app on first run; shown in
  Settings; entered/verified during pairing. The Android app stores its own copy
  (the phone app generates one too — the pair step is: enter the PC token into the
  phone **or** regenerate on one side and re-enter; either side's value must match).
- **Proxy auth**: SOCKS5 RFC1929 with user `netbridge` and password = token.
  HTTP proxy: `Proxy-Authorization: Basic base64(netbridge:token)`.
- **Bridge auth**: HMAC-SHA256 challenge/response (below). Timing-safe comparison
  on both ends.

## 3. Bridge framing

TCP; **one JSON object per line** (`\n`), UTF-8. Requests:

```json
{"id":7,"cmd":"net.mode.write","args":{"slot":0,"value":11}}
```

Responses always carry the request id:

```json
{"id":7,"ok":true,"result":{"slot":0,"value":11}}
{"id":8,"ok":false,"error":"auth required"}
```

Server may push events (reserved): `{"event":"signal","data":{…}}`.

### Handshake

```
C→S  {"id":1,"cmd":"auth","nonce":"<32hex random>"}
S→C  {"id":1,"ok":true,"result":{"nonce":"<server random>"}}
C→S  {"id":2,"cmd":"auth.verify","args":{"nonce":"<client nonce>","proof":"<hex>"}}
S→C  {"id":2,"ok":true,"result":{deviceInfo}}
proof = HMAC_SHA256(token, clientNonce + "|" + serverNonce) as lowercase hex
```

All commands other than `auth`/`auth.verify` are rejected until verified.

### Commands

| cmd | args | result |
|---|---|---|
| `ping` | – | `{"pong": ms}` |
| `device.info` | – | device/brand/androidVersion/sdkInt/appVersion/batteryLevel/batteryTempC/adbEnabled/writeSecureSettings |
| `net.info` | – | `subscriptions:[{subId,slot,carrier,preferredMode,networkType}], usbTethered, dataNetworkType` |
| `net.mode.read` | `{slot}` | `{slot,value,networkType}` |
| `net.mode.write` | `{slot,value}` | ok = Settings.Global write succeeded (WRITE_SECURE_SETTINGS) |
| `net.type` | – | live SignalSample (below) |
| `net.signal.start/stop` | `{intervalMs}` | ok (session flag; PC currently polls) |
| `proxy.stats` | – | running/port/bindAll/active/total/rx/tx/rates |
| `tether.status` | – | `{usbTethered}` |
| `logs.recent` | `{limit}` | array of log lines |

### SignalSample object

```json
{"timestampMs":1710000000000,"networkType":"LTE","nrState":"CONNECTED",
 "rsrp":-97,"rsrq":-9,"rssi":-71,"sinr":14,"cqi":12,"band":"B3",
 "pci":123,"tac":"45A1","cellId":"12345678","operator":"MCI (43211)",
 "isDataConnected":true,"family":"4G"}
```

Unavailable metrics are `null` (JSON). `family` ∈ `2G|3G|4G|5G|WLAN|UNKNOWN`.

## 4. Proxy wire behavior (port 59110)

- First byte `0x04`/`0x05` → SOCKS4/4a/5; otherwise → HTTP proxy dialect.
- SOCKS5: methods `0x00`(only when phone auth disabled)/`0x02`; RFC1929 user/pass;
  CONNECT (`0x01`) and UDP ASSOCIATE (`0x03`); BIND replies `0x07`.
- UDP ASSOCIATE: standard RSV/FRAG/ATYP framing, FRAG≠0 dropped, one client endpoint.
- HTTP: `CONNECT host:port` → `200 Connection Established`; absolute-form requests
  are rewritten (hop-by-hop headers stripped, `Connection: close` added).
- Failure replies: SOCKS REP codes (0x01 general, 0x04 host unreachable, 0x05 refused,
  0x06 TTL); HTTP 502 with text body.

## 5. adb private server

The Windows app speaks the standard **adb server protocol** (4-hex length-prefixed
service strings over TCP) to `127.0.0.1:5038`:

- `host:version`, `host:devices-l`
- `host-serial:<serial>:forward:tcp:59121;tcp:59110`
- `host:transport:<serial>` + `shell:<cmd>`; exit code captured by appending
  `; echo __RC__=$?` and parsing the last `__RC__=` marker (shell v1 has no rc).

Environment for the spawned server: `ADB_VENDOR_KEYS=<ProgramData>/NetBridge/keys/adbkey`,
`ANDROID_ADB_SERVER_PORT=5038`. The system adb (5037) is never touched.
